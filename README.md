# Enterprise Digital Experience Dashboard

A production-oriented enterprise dashboard built with Angular,
Node.js, NestJS, PostgreSQL, Docker, and GitHub Actions.

## Project Goals

- Responsive enterprise dashboard
- Secure authentication and role-based authorization
- REST API development with NestJS
- PostgreSQL database and Prisma ORM
- Automated testing and CI/CD
- Containerized development and deployment
- Application logging, monitoring, and health checks
- Scalable system design and performance optimization

## Architecture

The application will initially use a modular monolith architecture.

- Frontend: Angular and TypeScript
- Backend: Node.js, NestJS, and TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Testing: Jest, Supertest, and Playwright
- DevOps: Docker and GitHub Actions
